# Members Only

A private clubhouse message board built with Express, authentication with Passport and a Postgresql Database.

**Live demo:** Not currently deployed  



## Features

- User registration with input validation
- Secure password hashing with bcrypt
- Login and logout with Passport.js
- Create and view messages

## Skills demonstrated

- **Authentication and authorization:** separating visitors, members and admins
- **Backend development:** building Express routes and handling form submissions
- **Database design:** modeling users and messages, including their relationships
- **Security:** hashing passwords and validating/sanitizing user input

## Tech stack

- Node.js
- Express
- PostgreSQL
- Prisma
- Passport.js
- EJS
